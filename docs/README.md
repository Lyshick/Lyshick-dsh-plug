# docs · 经验沉淀

本目录存放使用与维护 DSH 插件过程中的经验沉淀，与插件安装无关（安装链接只读取 `plugins/` 下的子目录）。

## 内容约定

- **错误沉淀**：排查过的报错、踩过的坑与解决办法，建议一个主题一个文件，文件名描述问题本身，例如 `pnpm-tarball-url-mismatch.md`、`plugin-install-stuck.md`。
- **惊艳文档**：值得一读再读的优质文档、原理讲解与最佳实践总结，例如插件体系、pnpm 工作机制、cordis patch 加载顺序等主题。

## 建议的文件结构

```text
docs/
├── README.md          # 本文件：目录说明与索引
├── <主题>.md          # 单主题沉淀，直接平铺
└── assets/            # 文中引用的截图等资源（可选）
```
